# 数据来源与解释范围

本目录保存固定版本的数值样例，用于复算原团队报告中的限定问题。数据不是实时交通、旅游报价或景区库存。

参考材料为用户提供的[完整课程研究工程](https://github.com/Nick-zh-jsauhd/xinjiang-tourism-optimization)，固定版本为 `721853d880ab2b96d75d104d0d3e6d50338105a9`。每份文件的原始路径及URL见 [sources.json](sources.json)。本仓库程序重新实现求解和验证，不导入参考工程的程序模块。

| 本地文件 | 用途 |
| --- | --- |
| reference/route_products.csv | 63条候选线路的产品类型、区域、模型容量、舒适度等数值 |
| reference/baseline_portfolio.csv | 原18条入选线路，确定产品配额、区域与质量下界 |
| reference/cultural_sites.csv | 14个文化点的现场作业、安全缓冲和特殊准入标记 |
| reference/cultural_travel.csv | 乌鲁木齐及文化点之间的固定多模式交通标签 |
| reference/portfolio_expected.csv | 线路组合参考最优值，只用于核验输出 |
| reference/cultural_expected.csv | 调度参考最优值，只用于核验输出 |

参考最优值不参与求解目标、约束或选路过程。程序先从输入独立求解，再核对参考指标，避免把参考答案当作算法输入。

输入数据保留原数值，移除UTF-8 BOM并统一换行。每次运行对本地输入逐份计算SHA-256，写入 `results/generated/reproduction.json`。除规模、唯一标识、数值完整性外，求解后独立核对配额、区域、容量和质量约束。

## 参数的含义

- 线路容量是12天窗口内的模型承载量，不是已发生的接待人数。
- 综合分由固定权重与归一化指标构成，不是收入、利润或真实游客满意度。
- 质量代理以舒适度、缓冲日、长转场和平均交通时间阈值定义，不替代完整线路质量审计。
- 文化考察交通标签及安全缓冲含研究假设；特殊准入政策固定到指定组。
- 权重敏感性与需求压力情景由本仓库设定，用于分析政策与偏好变化，不代表需求预测或真实概率。
