# 个人分工与本轮补强

## 团队研究中的参与

我在新疆旅游线路优化团队中参与目标与约束设计、Python求解代码实现、情景仿真和结果验证，负责数据整理与分析。研究覆盖个人旅行、两年路线、三组考察与节假日接待四类决策场景。

具体体现为把覆盖、费用、工期和容量等诉求转为可比较的目标和约束，结合求解结果解释方案取舍，并核对数据口径、可执行条件和最优性的适用范围。团队报告中的整体结果与个人分工分开陈述。

## 2026年11月补强的可复算实现

本仓库近期使用AI辅助编程完善了以下模块，作为原研究的可运行展示：

1. **线路组合求解。** 将18线路选择写成0-1 MILP，显式表示产品类型配额、区域覆盖、容量下界及质量代理下界，导出选路清单。
2. **调度求解。** 用子集动态规划计算各组候选点集的最短往返路径，消除普通两组的交换对称，枚举可行分组并还原访问顺序。
3. **实验设计。** 增加5组权重敏感性和6组需求压力情景，观察组合变化、约束边界及不可行情况。
4. **验证。** 以小规模穷举作为独立对照，检查异常输入和约束；另外复算两项固定问题的参考最优值。共9项自动化测试、5项参考结果核验。
5. **交付。** 整理统一运行入口、中文结果报告、SVG图表、输入哈希和CI流程。

AI用于辅助实现与整理；验证依赖实际执行的求解、穷举对照、独立约束重算及参考结果比较。个人讲解时应能说明目标函数、约束设置、候选空间及不可行结果的含义。

## 结果解释

报告中的7.745%为固定候选产品空间的模型评分提升。本次实现复算得到7.744508%，属于保留位数差异。三团队99.187小时为固定特殊准入政策下的最晚完成时间。两项结果均不是实际运营业绩，也不覆盖原问题的所有可能政策与候选生成方式。
